## 一、项目概述

选题二：**基层医疗安全型预问诊与随访平台**（教学用辅助系统，不能宣称提供真实诊断或替代医生）

### 技术栈

| 层次 | 技术 |
|------|------|
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts |
| 业务后端 | Spring Boot 3.2 + JPA + Security + WebSocket + JWT |
| AI 服务 | Python + FastAPI（规则引擎 + 安全Agent + RAG） |
| 关系数据库 | MySQL 8.0（容器内） |
| 缓存/任务 | Redis（容器内，禁用状态可用） |
| 部署 | Docker Compose（5容器） |
| 接口文档 | OpenAPI/Swagger |
| 数据库迁移 | Flyway / JPA ddl-auto: update |

## 三、容器部署（Docker Compose）

### 端口映射

| 服务 | 容器内端口 | 主机端口 | 说明 |
|------|-----------|---------|------|
| MySQL | 3306 | 3307 | 本地有MySQL故错开 |
| Redis | 6379 | 6379 | |
| Backend | 8080 | 8090 | |
| AI Service | 8000 | 8000 | |
| Frontend (Nginx) | 80 | 8091 | |

### 启动方式

```bash
cd project/deploy
docker-compose build --no-cache backend  # 代码变更后需要
docker-compose up -d
```

### 已知问题

1. **Windows端口占用**：本地Docker Desktop用`wslrelay`进程可能占8080，已全部改到8090/8091
2. **容器内Maven连国外源**：已配阿里云镜像(`settings.xml`)，npm配npmmirror，pip配清华源
3. **数据库建表**：后端`application.yml`配了`ddl-auto: update` + Flyway禁用，会自动建表
4. **后端启动时序**：加了`restart: always` + HikariCP `initialization-fail-timeout: -1`，MySQL未就绪时自动重试
5. **中文编码**：所有Java/配置文件已转为纯ASCII（无BOM），中文字符串改为英文以避免编译乱码

### 后端本地开发（不用Docker）

```bash
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=dev
# 会使用H2内存数据库，无MySQL/Redis依赖
```
