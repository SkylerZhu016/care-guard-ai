## 自动化范围

- Java 规则：四条确定性规则、未知回答、未支持症状、混合覆盖和状态机。
- PostgreSQL 集成：V4 迁移、PATIENT 角色、v1 410、v2 写入、数字历史列为空、资料快照、补充信息、医务队列和 pgvector。
- Python：事实型 schema、规则等级可空、Provider 不升级、安全阻断、引用验证和适配器超时。
- Vue：四患者功能区、患者语言、无数字控件、未支持症状文案、角色路由、API 契约和生产构建。
- 浏览器：390px 与桌面核心流程、键盘焦点、危险文字提示、无控制台错误。

## 验收不变量

1. 新 AI 请求和新数据库写入均无数字评分。
2. 头痛、腹痛和自定义不适不自动得到 `ROUTINE`。
3. 混合症状不降低已命中的紧急等级。
4. 患者端不显示英文症状代码、规则代码、模型和覆盖状态。
5. 历史记录不被猜测转换。
6. AI 无证据、越界、降级或为无规则症状生成等级时进入阻断或人工复核。

最终命令与结果在本轮完整回归后更新；不得通过安装新依赖或切换数据库来规避失败。
