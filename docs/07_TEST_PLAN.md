# 07 测试规划

## 1. 测试策略
金字塔：单元（AI pytest / 后端 JUnit / 前端 Vitest）→ 接口（Spring MockMvc + FastAPI TestClient）→ 端到端（Playwright 主线 1 条）。所有测试可在 `MOCK_LLM=true` 下离线运行，禁止伪造结果。

## 2. 前端测试（Vitest + Playwright）
| 编号 | 用例 | 预期 |
|---|---|---|
| FE-01 | 登录表单空值/格式校验 | 阻断并提示 |
| FE-02 | 分步问诊必填校验（主诉/起病时间） | 阻断 |
| FE-03 | 路由守卫：未登录访问 /d/* → /login；角色不符 → /403 | 跳转正确 |
| FE-04 | 按钮权限 v-permission（患者不见「审核」按钮） | 不渲染 |
| FE-05 | 提交按钮防重（loading 期间禁用） | 仅一次请求 |
| FE-06 | SSE 断线 → 自动降级轮询 | 状态仍更新 |
| FE-07 | 401 → 自动刷新重放原请求 | 无感续期 |
| FE-08 | E2E 主线（演示 12 步压缩版） | 全通过 |
