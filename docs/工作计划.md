# 选题二：基层医疗安全型预问诊与随访平台 — 5天工作计划

## 第1天：项目搭建与需求分析

| 任务 | 具体内容 |
|------|---------|
| 需求分析 | 阅读选题文档，明确4种用户角色（患者/医务人员/随访人员/管理员）及各自功能需求 |
| 技术选型 | 确定技术栈：Vue3+TS+Element Plus（前端）/ Spring Boot（后端）/ FastAPI（AI服务）/ MySQL+Redis / Docker Compose 部署 |
| 项目初始化 | 脚手架搭建：project/ 目录结构（frontend/backend/ai-service/deploy/docs/tests） |
| 数据库设计 | 12张核心表设计：users, simulated_patients, visits, symptoms, triage_results, medical_guidelines, followup_plans, followup_tasks, safety_alerts, agent_runs, citations, audit_logs |
| 成果物 | 需求规格说明书（用户故事+用例图）、ER图、数据库设计文档 |

## 第2天：后端业务逻辑开发

| 任务 | 具体内容 |
|------|---------|
| 实体与仓库 | 12个JPA实体类 + 10个Repository接口，含主外键、唯一约束、索引 |
| 安全框架 | JWT Token认证 + RBAC权限控制（4角色分层）+ BCrypt密码加密 |
| 核心业务服务 | 预问诊提交服务（PreConsultService）、就诊状态机（PENDING→TRIAGING→REVIEW_REQUIRED→APPROVED→FOLLOWUP→CLOSED） |
| 随访管理 | 随访计划自动生成、周期性任务创建、完成状态跟踪 |
| 安全监控服务 | 红旗症状检测、安全告警管理、未审告警统计 |
| 配置与数据源 | Spring Security配置、WebSocket配置、Swagger/OpenAPI配置、Flyway迁移脚本（V1/V2） |
| 成果物 | 后端API接口、数据库迁移脚本、系统设计说明书（架构图+时序图） |

## 第3天：前端页面开发

| 任务 | 具体内容 |
|------|---------|
| 基础框架 | Vue3+TypeScript+Vite+Pinia+Element Plus+ECharts 搭建，路由配置，Axios封装 |
| 登录页 | 渐变背景 + 4种角色测试账号一键填充 + JWT Token管理 |
| 工作台仪表盘 | 统计卡片（4项指标）+ ECharts饼图 + 待处理就诊列表 + 安全告警列表 |
| 预问诊表单 | 分步骤症状信息填报 + 患者选择 + 动态症状条目 + 实时分诊结果展示 |
| 医生工作台 | 待处理就诊队列 + 可展开详情 + 审核操作 + 一键创建随访计划 |
| 随访管理页 | 随访计划列表 + 任务弹窗 + 完成随访反馈 |
| 安全监控面板 | 告警分类统计 + 类型/严重程度筛选 + 审核操作 |
| 指南检索页 | 分类筛选 + 关键词搜索 + 原文对照卡片展示 |
| 成果物 | 前端全部7个页面、接口联调文档 |

## 第4天：AI 服务与安全 Agent 开发

| 任务 | 具体内容 |
|------|---------|
| AI分诊引擎 | 规则引擎开发：7类红旗症状检测（胸痛/呼吸困难/意识模糊等）+ 既往史风险评分 + 年龄分层 |
| 安全Agent | 多Agent安全复核：内容安全Agent（提示词攻击检测）、隐私合规Agent（身份证/手机号脱敏检测）、越权诊断Agent（禁止替代医生诊断） |
| RAG检索服务 | 6大类基层诊疗指南（心血管/内分泌/呼吸/神经内科/感染）、关键词相关度排序 |
| 版本追踪 | 每次AI运行记录模型版本/Prompt版本/知识库版本 + 引用来源记录 |
| 成果物 | AI服务接口文档、安全审核机制说明 |

## 第5天：部署、测试与文档

| 任务 | 具体内容 |
|------|---------|

| 代码仓库 | Git初始化、.gitignore配置、创建xzm分支并推送GitHub |
| 文档撰写 | 系统设计说明书、API接口文档、数据库设计文档、README |
| 成果物 | 可运行Demo、Docker Compose一键启动、Git仓库、完整实训报告 |
