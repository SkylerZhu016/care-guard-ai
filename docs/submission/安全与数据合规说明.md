# 安全与数据合规说明

## 1. 系统定位声明
本系统是**教学与课程实训用途的辅助系统**：
- 不提供真实医疗诊断、不开具处方、不替代医生；
- 全部病例为**合成数据**；知识库仅使用**公开、合法来源**的指南与资料；
- 不接入、不保存任何未经授权的真实患者医疗数据；
- 所有 AI 输出页面固定展示免责声明。

## 2. 医疗安全边界（四层防线）
| 层 | 机制 | 说明 |
|---|---|---|
| L1 确定性规则 | 规则引擎（DB 配置 JSON DSL） | 红旗症状/特殊人群/药物禁忌硬检查；**CRITICAL 不可被 AI 降级** |
| L2 安全审查 Agent | 确定性 checker + LLM 复核 | 拦截诊断词/处方词/缺免责/红旗遗漏/引用缺失/注入；FAIL 即阻断并告警 |
| L3 人工审核 | 医务人员审核队列 | AI 内容**永不绕过人工直接对患者展示**；修改留版本快照 |
| L4 表达约束 | 输出安全话术 | 高风险统一「建议尽快寻求专业医疗帮助」；禁止确定性诊断表述 |

## 3. 对抗性防护
| 威胁 | 防护 |
|---|---|
| Prompt 注入 | 输入侧注入特征清单拦截 + safety_alerts 告警 + 攻击样本安全测试 |
| 系统提示词窃取 | 系统提示永不回显；输出审查扫描 |
| 隐私泄露 | PII 正则扫描输出；列表接口服务端掩码（姓名/手机/证件） |
| 越权访问 | Spring Security URL+方法双层鉴权；患者数据 owner 校验；越权访问写告警 |
| 恶意上传 | 扩展名+MIME 白名单（txt/md/pdf）+10MB 限制+文件哈希落库 |
| 认证攻击 | BCrypt 密码哈希；连续失败 5 次锁定 15 分钟；JWT 短期 access+可吊销 refresh 轮换 |

## 4. 可追溯与审计
- 全链路留痕：每次 AI 运行记录**模型版本、Prompt 版本、知识库版本、规则版本**、逐步输入输出快照、token 用量；
- 引用可追溯：citations 记录文档/章节/页码/原文片段/检索得分/知识库版本；
- 审计日志：操作用户/角色/动作/对象/前后摘要/IP/traceId，只增不改；
- 人工修改留痕：review_records 保存 AI 原始快照与修改后内容，支持版本对比。

## 5. 密钥与配置安全
- LLM API Key、JWT 密钥、数据库密码**仅从环境变量读取**；仓库仅含 `.env.example`；
- model_configs 表不存密钥；日志与审计禁存密码、Token、API Key（启动自检扫描）。

## 6. 数据生命周期
| 数据 | 策略 |
|---|---|
| 合成病例 | 仅演示，可随时经 reset 脚本重置 |
| 审计日志 | 课程期内保留，只增不改 |
| 知识库文档 | 软删除（保留版本与引用链） |
| 上传文件 | MinIO 私有桶，鉴权下载，禁止公开直链 |
