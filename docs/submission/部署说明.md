# 部署说明

## 1. 环境要求
- Docker 24+ 与 Docker Compose v2
- 或本地开发：JDK 17 / Node 22 / Python 3.11 / PostgreSQL 16(+pgvector) / MinIO

## 2. 一键部署（推荐）
```bash
cd deploy
cp .env.example .env        # 按需修改密钥（见第 4 节）
docker compose up -d --build
docker compose ps           # 5 个服务全部 healthy
```
访问：前端 http://localhost ；后端接口文档 http://localhost:8080/swagger-ui.html ；AI 服务健康 http://localhost:8000/health

## 3. 服务清单
| 服务 | 镜像/构建 | 端口 | 健康检查 |
|---|---|---|---|
| db | pgvector/pgvector:pg16 | 5432 | pg_isready |
| minio | minio/minio | 9000/9001 | /minio/health/live |
| backend | ./backend (Dockerfile) | 8080 | /actuator/health |
| ai-service | ./ai-service (Dockerfile) | 8000 | /health |
| frontend | ./frontend (multi-stage→nginx) | 80 | / |

启动顺序经 `depends_on + condition: service_healthy` 保证：db → minio → backend/ai-service → frontend。

## 4. 环境变量（.env.example）
| 变量 | 默认 | 说明 |
|---|---|---|
| POSTGRES_PASSWORD | med_dev_123 | 数据库密码（演示环境可保留） |
| JWT_SECRET | 32+ 随机串 | **生产必须改** |
| INTERNAL_TOKEN | internal_dev_token | 后端⇄AI 内部令牌 |
| MINIO_ROOT_USER/PASSWORD | minioadmin/minioadmin | 对象存储 |
| LLM_API_BASE / LLM_API_KEY / LLM_MODEL | 空 | 真实模型；留空即 Mock |
| MOCK_LLM | true | 离线演示开关 |
| EMBEDDING_API_BASE/KEY/MODEL | 空 | 留空用 HASH 本地嵌入 |

**纪律：仓库只提交 `.env.example`，禁止提交真实 `.env` 与任何密钥。**

## 5. 初始化与演示数据
- Flyway 随 backend 首次启动自动执行 V1（建表）/V2（种子：账号、12 条规则、5 个 Prompt、7 篇指南、3 个合成患者）。
- ai-service 启动时自动为缺失 embedding 的知识分块补算向量。
- 一键重置演示数据：`./data-pipeline/reset_demo.sh`（Windows: `reset_demo.ps1`）。

## 6. 本地开发
```bash
# 数据库+MinIO
cd deploy && docker compose up -d db minio
# 后端
cd backend && ./mvnw spring-boot:run
# AI 服务
cd ai-service && pip install -r requirements.txt && uvicorn app.main:app --port 8000
# 前端
cd frontend && npm install && npm run dev   # 已配置 /api → 8080 代理
```

## 7. 备份与运维
- 数据卷：pgdata / miniodata；备份 `docker exec db pg_dump -U med medplatform > backup.sql`
- 日志：`docker compose logs -f backend`；审计日志在库内 audit_logs 表。
- 演示环境（MOCK_LLM=true）与开发环境（真实 LLM）仅以 .env 区分。

## 8. 常见故障
| 现象 | 处理 |
|---|---|
| db 一直 unhealthy | 删除 pgdata 卷重建；检查 5432 端口占用 |
| 前端 502 | backend 未就绪，等待 healthcheck 通过 |
| AI 调用失败 | 确认 MOCK_LLM 或 LLM_API_KEY 配置 |
| 指南检索无结果 | 确认 ai-service 已完成 embedding 回填（查 agent 日志） |
