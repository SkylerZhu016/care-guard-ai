# 前后端接口文档

> 接口合同全文见 `docs/04_API_PLAN.md`（权威版本，含请求/响应结构、错误码、幂等与事务要求）。本文件为摘要速查。运行时 Swagger UI：`http://localhost:8080/swagger-ui.html`。

## 1. 通用约定
- 前缀 `/api/v1`；鉴权 `Authorization: Bearer <accessToken>`；内部接口 `/api/internal` 走 `X-Internal-Token`。
- 分页 `?page=0&size=20&sort=createdAt,desc` → Spring Page JSON。
- 统一错误体 `{code, message, traceId}`：40001 参数 / 40101 未登录 / 40102 锁定 / 40301 无权限 / 40302 越权数据 / 40401 不存在 / 40901 状态冲突 / 40902 重复提交 / 50301 AI 不可用。
- 写操作幂等：客户端生成 `Idempotency-Key` + 业务唯一约束兜底。

## 2. 接口分组速查（方法 路径 → 说明 [角色]）
### 认证
- POST `/auth/register` 患者注册 [公开]
- POST `/auth/login` 登录 → {accessToken, refreshToken, user} [公开]
- POST `/auth/refresh` 刷新 [公开]
- POST `/auth/logout` 登出 ｜ GET `/auth/me` 当前用户 ｜ PUT `/auth/password` 改密

### 用户与角色 [ADMIN]
- GET/POST `/users`，PUT `/users/{id}`，PUT `/users/{id}/status`，PUT `/users/{id}/password`
- GET `/roles`，PUT `/roles/{code}/permissions`

### 患者档案
- GET/POST `/patients`，GET/PUT `/patients/{id}` [PATIENT本人 / DOCTOR / FOLLOWUP / ADMIN]
- POST `/patients/{id}/histories|allergies|medications`，DELETE 同路径 + `/{subId}`

### 预问诊
- POST `/visits/draft` 存草稿 [PATIENT]
- GET `/visits/drafts` 草稿列表 [PATIENT]
- POST `/visits` 提交（启动 AI 流水线）[PATIENT]
- GET `/visits` 分页（患者仅本人，列表脱敏）
- GET `/visits/{id}` 详情（未 REVIEWED 时患者不可见 AI 内容）
- PUT `/visits/{id}/supplement` 补充 [PATIENT，仅 NEED_INFO]
- GET `/visits/{id}/status-logs` 流转记录
- POST `/visits/{id}/retry` 失败重跑 [DOCTOR/ADMIN]
- GET `/visits/{id}/agent-run` 最新运行

### 分诊（只读）[DOCTOR/ADMIN]
- GET `/triage/visits/{visitId}` 汇总 ｜ `/extractions` ｜ `/rule-hits` ｜ `/citations`

### 规则
- GET/POST `/rules`，PUT `/rules/{id}`（生成新版本），PUT `/rules/{id}/toggle`，GET `/rules/{id}/versions` [ADMIN]
- POST `/rules/test` 在线测试 [ADMIN/DOCTOR]

### 指南与知识库
- GET/POST `/guidelines`（multipart 上传），PUT `/guidelines/{id}`，PUT `/guidelines/{id}/toggle`，DELETE `/guidelines/{id}` [ADMIN]
- GET `/knowledge/documents/{id}/chunks`，POST `/knowledge/search`，POST `/knowledge/reindex`，GET `/knowledge/versions`

### Agent 运行
- GET `/agent-runs` 分页 ｜ GET `/agent-runs/{id}` 详情+步骤 [DOCTOR/ADMIN]
- GET `/agent-runs/{id}/events` **SSE 进度**（支持 `?token=`）

### 审核 [DOCTOR]
- GET `/reviews/queue` 待审队列
- POST `/reviews` {visitId, action: APPROVE/REJECT/REQUEST_INFO, comment, modifiedSummary?, modifiedRiskLevel?}
- GET `/reviews/visits/{visitId}` 审核历史

### 随访
- POST `/followup-plans`，POST `/followup-plans/{id}/start|pause|resume|terminate`，GET `/followup-plans[/{id}]`
- GET `/followup-tasks` 分页过滤，POST `/followup-tasks/{id}/claim|start`
- POST `/followup-tasks/{id}/complete` {record:{contactResult, symptomChange, note, feedback}}
- POST `/followup-tasks/{id}/delay|lost|escalate`
- GET `/followup-tasks/trends?patientId=` 趋势数据

### 安全与审计 [ADMIN]
- GET `/safety-alerts`，POST `/safety-alerts/{id}/handle` {action: ACK/CLOSE, note}
- GET `/audit-logs` 多维过滤
- GET/PUT `/admin/configs[/{key}]`，GET `/admin/models`，PUT `/admin/models/{id}`，GET/POST `/admin/prompts…`

### 文件
- POST `/files` multipart ≤10MB ｜ GET `/files/{id}/download`

## 3. 内部接口（后端⇄AI，X-Internal-Token）
| 方向 | 方法与路径 | 说明 |
|---|---|---|
| 后端→AI | POST `/internal/pipeline/start` | 启动流水线（异步） |
| 后端→AI | POST `/internal/knowledge/ingest` | 摄取文档分块 |
| 后端→AI | POST `/internal/search` | 向量+关键词检索 |
| AI→后端 | POST `/api/internal/agent-runs/{runId}/completed` | 流水线完成回调（触发状态机） |
| AI→后端 | GET `/api/internal/files/{fileId}/download` | 取文档原文 |
| AI→后端 | POST `/api/internal/knowledge/documents/{docId}/ingested` | 摄取完成置 ENABLED |
