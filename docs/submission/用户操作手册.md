# 用户操作手册

> 本系统为教学用辅助系统，所有 AI 生成内容仅供教学参考，**不能替代医生诊断**。

## 1. 通用操作
- **登录/注册**：打开首页 → 输入账号密码（新用户点「注册患者账号」，仅开放患者角色自助注册；医务人员/随访/管理员账号由管理员创建）。
- **个人中心**：右上角用户名 → 修改密码、查看角色。
- **防呆设计**：所有提交按钮点击后进入加载态防止重复提交；表单必填项有即时校验。

## 2. 患者模拟用户
| 功能 | 路径 | 说明 |
|---|---|---|
| 首页 | /p/home | 统计概览 + 快捷入口 |
| 模拟患者档案 | /p/archive | 新建/编辑档案；在「管理」抽屉中维护既往史、过敏史、用药记录 |
| 新建预问诊 | /p/visit-new | 分 10 步填写；每步可「保存草稿」；最后一步确认提交（自动生成幂等键防重复） |
| 我的预问诊 | /p/visits | 「全部记录/草稿箱」切换；草稿可继续填写 |
| 预问诊详情 | /p/visits/:id | 处理中显示五段流水线进度（SSE 实时）；被退回时提示补充；**已审核后**才可查看建议 |
| 补充信息 | /p/visits/:id/supplement | 修改后重新进入审核队列 |
| 我的随访 | /p/followups | 查看计划与任务；打开任务可预填随访反馈 |

## 3. 医务人员
| 功能 | 路径 | 说明 |
|---|---|---|
| 工作台 | /d/workbench | 待审核数/危急数统计；队列按风险排序，可筛选 |
| 审核详情 | /d/review/:id | 四栏对照：原始信息 → 结构化+规则命中 → AI 摘要（可编辑风险等级与关注点） → 引用原文+安全审查清单；底部「通过 / 驳回 / 要求补充」 |
| 创建随访计划 | /d/followup-plan-new/:visitId | 审核通过后一键跳转；设置频率/次数/内容项，可「创建并启动」 |
| 患者档案查询 | /d/patients | 只读检索（列表脱敏） |

## 4. 随访人员
| 功能 | 路径 | 说明 |
|---|---|---|
| 任务看板 | /f/board | 今日/逾期/高风险/全部四个视角；认领、开始 |
| 任务详情 | /f/task/:id | 填写随访记录（联系结果+症状变化）；可延期/失联/风险升级（升级自动生成安全告警） |
| 随访趋势 | /f/trends | 选择患者查看症状变化折线图与明细 |

## 5. 系统管理员
| 功能 | 路径 | 说明 |
|---|---|---|
| 用户/角色 | /a/users、/a/roles | 建用户、启停、重置密码；按角色勾选权限 |
| 指南与知识库 | /a/guidelines | 上传 txt/md/pdf → 自动摄取分块；启停/删除；检索测试；重建索引 |
| 规则管理 | /a/rules | 规则 CRUD（JSON 条件表达式）、启停、版本历史、在线测试（命中预览） |
| 模型管理 | /a/models | 查看/切换默认模型（密钥仅服务端环境变量，不在页面显示） |
| Prompt 版本 | /a/prompts | 查看五个 Agent 的 Prompt；新增版本、启停 |
| Agent 运行记录 | /a/agent-runs | 每次流水线的五步骤、token、耗时、四版本、输入输出快照 |
| 安全告警 | /a/alerts | 确认/关闭告警（注入攻击、审查失败、越权等） |
| 审计日志 | /a/audit-logs | 按操作人/类型/时间过滤；含 traceId 全链路追踪 |
| 系统配置 | /a/configs | 免责声明、知识库版本等 KV |

## 6. 常见问题
- **看不到 AI 建议？** AI 内容必须经医务人员审核通过后才对患者可见，这是安全设计。
- **提交后一直"处理中"？** 请稍候，五段流水线通常数秒完成；若 AI 服务不可用会转入失败态并由人工处理。
- **文件上传失败？** 仅支持 txt/md/pdf 且 ≤10MB。
