# 10 分钟演示流程

1. 用 `patient / Demo123!` 登录，展示患者端四个功能区。
2. 新建头痛记录，填写事实字段并提交；展示页面明确说明“记录并交由人工复核”，不出现自动常规等级。
3. 再新建胸口不适，在特异问题中选择同时呼吸困难；展示即时优先审核提示和直接提交。
4. 用 `clinician` 登录，分层核对患者原话、事实答案、`PARTIAL/FULL/NONE` 覆盖、规则结果、AI 摘要和网络引用。
5. 完成人工终审，明确选择不随访或创建 `GENERAL_FOLLOWUP_V1` 并激活。
6. 用 `followup` 执行一项任务；用 `admin` 查看知识来源、运行、告警和审计。
7. 停止 AI 后再次提交，展示问诊仍进入人工队列且不会伪造 AI 成功结果。

演示数据使用不含真实身份信息的测试夹具。系统不构成诊断或处方。
