# 安全与合规

## 边界

只允许合成病例和公开指南；禁止真实姓名、证件号、电话、住址和真实病历。系统持续展示“教学模拟”，不输出诊断、处方或剂量。

## 控制

- JWT + 角色和资源所有权双重校验；前端隐藏菜单不构成授权。
- BCrypt 密码；密钥来自环境变量；`deepseek_api.txt` 和 `.env` 被 Git 忽略。
- 规则优先、AI 紧急度单调、引用存在性校验、人工终审。
- 输入检查提示注入、角色伪造、隐私标识和超长文本；输出检查越权诊断、药品剂量、免责声明和引用。
- 审计只保存动作、结果和脱敏元数据；不保存 token、密码、原始 Prompt 或完整自由文本。

## 威胁模型

| 威胁 | 控制 | 失败路径 |
|---|---|---|
| 提示词注入 | 输入模式检测 + 固定工作流 | BLOCKED + 安全告警 |
| AI 降低红旗风险 | 后端紧急度单调校验 | 拒绝结果、保留规则等级 |
| 伪造引用 | chunk 白名单校验 | 转人工并告警 |
| 越权访问 | 后端 RBAC/所有权 | 统一 403 |
| AI 超时 | 超时和有限失败记录 | 规则结果进入人工队列 |
| 密钥泄露 | 环境注入、忽略规则、日志脱敏 | 启动只报告缺失变量名 |
