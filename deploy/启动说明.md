# 一键启动指南

## 前提：安装 Docker Desktop

1. 下载安装 [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/)
2. 启动 Docker Desktop，等待引擎就绪（任务栏鲸鱼图标不再转圈）
3. 确保 WSL2 已启用（Docker Desktop 安装向导会引导）

## 启动所有服务

打开终端（PowerShell 或 CMD），进入项目根目录：

```bash
cd D:\thr\26年大三下暑期实训\期末大作业

# 复制环境变量配置（已配置好 DeepSeek API Key）
copy .env deploy\.env

# 一键启动全部 7 个服务
docker compose -f deploy\docker-compose.yml up -d

# 查看启动日志
docker compose -f deploy\docker-compose.yml logs -f
```

首次启动需要下载镜像、编译后端、安装 npm 依赖，约 5-10 分钟。之后启动只需 30 秒。

```bash
docker compose -f deploy\docker-compose.yml down
```

## 数据重置

```bash

bash data-pipeline/reset_demo.sh

```
